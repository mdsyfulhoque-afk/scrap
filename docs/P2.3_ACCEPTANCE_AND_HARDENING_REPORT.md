3. **HIGH H2:** Checksum scope — Added `structured_data_checksum` and `structured_data_size_bytes` to extraction metadata

## 17. Remaining Limitations

1. HTML extraction is basic (stdlib parser only)
2. XML depth limited to 5 levels, 50 children per node
3. CSV row limit: 1000 rows for structured data
4. No PDF/DOCX/XLSX support
5. Markdown parsing is heuristic (not CommonMark)
6. 31 pre-existing unavailable test artifacts
